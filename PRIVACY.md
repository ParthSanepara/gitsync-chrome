# GitSync Privacy Policy

_Last updated: 2026-09-17_

GitSync is a Chrome extension with a single purpose: sync branches between GitHub repositories.

## Data collection

GitSync does not collect, transmit, sell, or share any personal data or usage data. It has no
analytics, telemetry, or tracking, and there is no GitSync server.

## Data stored on your device

The current version stores no data. Future versions that connect to GitHub will store:

- access tokens you provide, in the browser's session storage, cleared when the browser closes
- sync configurations you save, in the browser's local storage

This data never leaves your browser, except that tokens are sent directly to GitHub
(`api.github.com`, `github.com`) to perform the operations you request.

## Changes

Changes to this policy are published in this file, with its history in the project repository.
